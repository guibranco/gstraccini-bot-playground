# GStraccini-bot Playground 🤖 :octocat:

Welcome to the **GStraccini-bot Playground**! 🎮 This repository is a temporary space where we experiment with code, tests, and new features for the GStraccini-bot 🤖. It serves as a playground to try out new ideas and fine-tune the bot before moving to a more stable environment.

## 🚀 Overview

This repository contains:

- Temporary code snippets for bot functionality 💻.
- Tests and experiments to explore new features 🔬.
- Code written in **HTML**, **CSS**, **JavaScript**, with some parts in **PHP** and **SQL (MariaDB/MySQL)** 📝.

## 🛠️ Technologies Used

- **HTML** for structure and layout 🌐
- **CSS** for styling 🎨
- **JavaScript** for functionality 🖥️
- **PHP** for backend logic 🔧
- **SQL** (MariaDB/MySQL) for database interactions 💾

## ⚙️ Getting Started

To get up and running with the GStraccini-bot Playground, follow these steps:

### 🧰 Prerequisites

- [PHP](https://www.php.net/) for PHP-based code 🔍.
- A **MariaDB/MySQL** database for the backend 💽.

### 📥 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/guibranco/gstraccini-bot-playground.git
   ```

2. Navigate to the project folder:

   ```bash
   cd gstraccini-bot-playground
   ```

3. Install dependencies for JavaScript code:

   ```bash
   composer install
   ```

4. Set up your **MariaDB/MySQL** database and import any required SQL scripts (found in the `database/` folder) 🏗️.
